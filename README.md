# Seismic retrofit with FVD and PBEE

Reproducible OpenSeesPy research workflow for the SPEAR irregular RC frame.

Current milestones:

- SPEAR-M0 accepted and hash-locked as an engineering benchmark;
- modal and four-direction pushover gates passed;
- baseline NLTHA driver and nonlinear FVD element infrastructure available;
- ground-motion selection, baseline record campaign and FVD design remain the
  active next stages.

See `validation/SPEAR_M0_ENGINEERING_ACCEPTANCE.md` and
`models/SPEAR/fvd/README.md`.
